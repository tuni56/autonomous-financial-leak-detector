# Autonomous Financial Leak Detector (AFLD)
## AI-Driven Revenue Recovery & Audit Agent

**Stop losing money in silent anomalies. Start recovering it with Agentic AI.**

### 🚀 Overview
AFLD is a production-ready **Agentic Workflow** built on **AWS Bedrock** and **Model Context Protocol (MCP)**. It goes beyond simple detection by reasoning through historical data and real-time transactions to identify "invisible" financial leaks.

### 🏗️ Architecture
* **Brain:** Claude 3.5 Sonnet (Amazon Bedrock)
* **Context:** MCP Tools (S3 & Redshift Integration)
* **Environment:** Managed by `uv` for high-performance Python isolation.
* **Infrastructure:** Terraform (IaC).
